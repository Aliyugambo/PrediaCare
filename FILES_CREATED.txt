================================================================================
API ENDPOINTS AVAILABLE
================================================================================

POST /api/auth/register
  Input: { name, email, password, role }
  Output: { success, message }
  Purpose: Register new user account

POST /api/auth/login
  Input: { email, password, role }
  Output: { success, message, redirectUrl, user }
  Purpose: Authenticate user and create session

POST /api/auth/logout
  Input: none
  Output: { success, message }
  Purpose: Destroy user session

GET /api/auth/user
  Input: none (uses session cookie)
  Output: { success, user }
  Purpose: Retrieve current authenticated user info

SUPPORT & TROUBLESHOOTING
================================================================================

MySQL connection failing?
  → Check MySQL is running
  → Verify .env credentials
  → Run node init-db.js again

Port 5000 already in use?
  → Kill process: lsof -i :5000 && kill -9 <PID>
  → Or change PORT in .env

Login not working?
  → Verify database initialized: node init-db.js
  → Check backend running: npm start
  → Check HTML served over HTTP: http://localhost
  → Check browser console (F12) for errors

CORS errors?
  → Make sure backend on http://localhost:5000
  → Make sure HTML files on http://localhost (not file://)
  → Use a web server (Python, Node, PHP, etc)

Still having issues?
  → Read VISUAL_SETUP_GUIDE.md troubleshooting section
  → Check terminal output for error messages
  → Review browser console (F12)
  → Look in backend/SETUP_GUIDE.md
