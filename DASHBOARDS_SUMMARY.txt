================================================================================
                        INTEGRATION DETAILS
================================================================================

BACKEND API CALLS:

Patient Dashboard:
  1. GET /api/auth/user → Load user profile
  2. POST /api/auth/logout → Logout user
  
Doctor Dashboard:
  1. GET /api/auth/user → Load doctor profile
  2. POST /api/auth/logout → Logout doctor

AUTHENTICATION FLOW:

  User visits dashboard
         ↓
  Page load → JavaScript executes
         ↓
  Fetch /api/auth/user with credentials: 'include'
         ↓
  ├─ Success (200) → Display dashboard with user data
  └─ Fail (401) → Redirect to sign-in.html

LOGOUT FLOW:

  User clicks Logout button
         ↓
  handleLogout() function executes
         ↓
  POST /api/auth/logout with credentials: 'include'
         ↓
  ├─ Success → Redirect to sign-in.html
  └─ Fail → Show error alert
